# sdfg

This repository accepts `.txt` files (and all other file types). There are no restrictions on uploading `.txt` files.

## How to Upload Files

### Via GitHub Web Interface
1. Navigate to the repository on GitHub.
2. Click the **Add file** button near the top of the page.
3. Select **Upload files**.
4. Drag and drop your `.txt` files or click **choose your files** to browse.
5. Add a commit message and click **Commit changes**.

### Via Git Command Line
```bash
git add yourfile.txt
git commit -m "Add yourfile.txt"
git push
```
